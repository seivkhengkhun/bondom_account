Get an API key

Base URL

{{ base_url }}/api/v1

All responses are JSON. The API version is in the path, so /api/v1 will not change shape underneath you.

Authentication

Send your key on every request, either way: 

Authorization: Bearer bk_live_xxxxxxxx_yyyyyyyyyyyy
X-API-Key: bk_live_xxxxxxxx_yyyyyyyyyyyy

Keys are shown once at creation and stored only as a hash — we cannot recover one for you. Treat a key like a password: keep it server-side, never in browser or mobile code, and revoke it immediately if it leaks.

Rate limits

{{ rate_limit }} requests per minute per key, on a sliding window. Every response carries your current position: 

X-RateLimit-Limit: {{ rate_limit }}
X-RateLimit-Remaining: 57
X-RateLimit-Reset: 60

Exceeding it returns 429 with a Retry-After header. Back off for that many seconds rather than retrying immediately.

Example: buy a product

Purchases are paid from your wallet balance — top up at /wallet. There is no card flow in the API.

Request

POST {{ base_url }}/api/v1/orders
X-API-Key: bk_live_xxxxxxxx_yyyyyyyyyyyy
Content-Type: application/json

{"product_id": 2, "quantity": 1}

Errors

Every failure uses the same shape, so you only need one handler: 

{
  "error": {
    "code": "insufficient_balance",
    "message": "Wallet balance $0.50 is short of $10.00.",
    "status": 402,
    "request_id": "9f2c1a77b0e34d18"
  }
}

Quote the request_id in any support message — it identifies the exact call in our logs.

const BASE = "{{ base_url }}/api/v1";

async function buy(productId, quantity = 1) {
  const res = await fetch(`${BASE}/orders`, {
    method: "POST",
    headers: {
      "X-API-Key": process.env.BONDOM_API_KEY,
      "Content-Type": "application/json",
    },
    body: JSON.stringify({ product_id: productId, quantity }),
  });

  const data = await res.json();
  if (!res.ok) {
    // Every failure has the same shape.
    throw new Error(`${data.error.code}: ${data.error.message}`);
  }
  return data.items;          // delivered credentials
}

$base = "{{ base_url }}/api/v1";

function bondom($method, $path, $body = null) {
    global $base;
    $ch = curl_init($base . $path);
    curl_setopt_array($ch, [
        CURLOPT_RETURNTRANSFER => true,
        CURLOPT_CUSTOMREQUEST  => $method,
        CURLOPT_HTTPHEADER     => [
            "X-API-Key: " . getenv("BONDOM_API_KEY"),
            "Content-Type: application/json",
        ],
        CURLOPT_POSTFIELDS => $body ? json_encode($body) : null,
    ]);
    $raw    = curl_exec($ch);
    $status = curl_getinfo($ch, CURLINFO_HTTP_CODE);
    curl_close($ch);

    $data = json_decode($raw, true);
    if ($status >= 400) {
        throw new Exception($data["error"]["code"] . ": " . $data["error"]["message"]);
    }
    return $data;
}

$order = bondom("POST", "/orders", ["product_id" => 2, "quantity" => 1]);

import os
import requests

BASE = "{{ base_url }}/api/v1"
SESSION = requests.Session()
SESSION.headers["X-API-Key"] = os.environ["BONDOM_API_KEY"]


class BondomError(Exception):
    pass


def request(method, path, **kwargs):
    res = SESSION.request(method, BASE + path, timeout=30, **kwargs)
    data = res.json()
    if not res.ok:
        err = data["error"]
        raise BondomError(f"{err['code']}: {err['message']}")
    return data


def buy(product_id: int, quantity: int = 1) -> list[str]:
    order = request("POST", "/orders",
                    json={"product_id": product_id, "quantity": quantity})
    return order["items"]


print(buy(2))
